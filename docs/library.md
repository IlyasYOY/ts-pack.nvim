# Parser Library Reference

`require('ts-pack.library')` exposes the optional parser registry used by `ts-pack.nvim` examples and by users who do not want to write every parser spec by hand.

Keep this file in sync with [`lua/ts-pack/library.lua`](../lua/ts-pack/library.lua) whenever the registry changes.

## API

### `library.registry`

`library.registry` is a table keyed by parser name. Each value is a parser spec fragment that can include source, revision, build, query, metadata, and dependency fields. The registry currently contains 329 parser entries. Entries without `src` are placeholders for query or dependency relationships and are not returned as install specs by `library.select()`.

### `library.select(names)`

`library.select(names)` accepts a list of parser names and returns specs accepted by `require('ts-pack').add()`. It validates parser names, expands `requires` dependencies before dependents, removes duplicate selections, deep-copies each spec, adds the parser `name`, removes `requires`, and raises an error for unknown parsers or dependency cycles. When bundled queries exist for a selected parser, `select()` clears checkout `queries` and sets `bundled_queries = true`.

## Registry Fields

- `src`: upstream parser repository URL.
- `version`: commit, tag, or ref used by installation and updates.
- `branch`: optional remote branch used for clone/fetch and as `origin/<branch>` when `version` is unset.
- `location`: optional subdirectory inside the checkout that contains the grammar.
- `data.filetype`: Neovim filetype names registered for the parser when they differ from the parser name.
- `data.features`: optional automatic feature setup; `true` enables highlights, indent, and folds, while a table enables selected features.
- `requires`: parser names selected before this parser by `library.select()`.
- `queries`: query directory copied from the parser checkout before bundled query handling.
- `generate`: whether `tree-sitter generate` runs before compiling the parser.
- Bundled queries are not stored as registry fields. They are available from `lua/ts-pack/bundled_queries/<parser>/` and are applied by `library.select()`.
